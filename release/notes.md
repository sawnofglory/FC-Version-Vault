**What's new**

- Fix: **Undo** could stop half way with "Access to the path is denied" when the app was not run as administrator. Undo now checks this before moving anything and offers to restart as administrator. If an Undo was left half done by v1.0, click **Undo** again in this version and it finishes.
- The app's version number is now shown at the top of the window.

If you have v1.0, open it and click **Update** on the yellow strip. New here? Download `FC-Version-Vault-Setup.exe`.
